# LeetCode DSA Journey 🚀

This repository contains my **LeetCode problem-solving journey**, where I practice Data Structures and Algorithms using **Java**.

The repository is organized by **DSA patterns** rather than simply by problem number. This structure helps me focus on the underlying problem-solving techniques and recognize patterns across different problems.

## 📂 Repository Structure

Problems are organized into patterns such as:

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Stack
- Linked List
- 1-D Dynamic Programming
- Greedy
- Heap / Priority Queue
- Bit Manipulation
- String / Simulation

Each pattern contains the related LeetCode problems along with their Java solutions and problem documentation.

## 🎯 Why Pattern-Based?

Instead of treating every LeetCode problem as a completely different problem, I organize problems based on the **DSA patterns and techniques** used to solve them.

This makes it easier to:

- Recognize patterns faster
- Revisit similar problems together
- Understand how techniques apply to different problems
- Improve problem-solving skills
- Prepare systematically for coding interviews

## 🛠️ Language

**Java**

## 📚 Learning Approach

I am following a structured DSA learning path and continuously adding new problems to this repository as I practice.

The repository will evolve continuously as I learn new concepts, solve new problems, and strengthen my problem-solving skills.
